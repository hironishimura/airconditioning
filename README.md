# 空気線図（Psychrometric Chart）

ブラウザで動く空気線図作図アプリです。ビルド不要で、`index.html` をブラウザで開くだけで使えます。

## 機能

- **線図の描画**: 乾球温度・絶対湿度・相対湿度（10%刻み）・湿球温度・比エンタルピー・比容積・飽和曲線
- **カーソル読み取り**: 線図上にマウスを置くと、その点の状態量（乾球・湿球・相対湿度・絶対湿度・露点・比エンタルピー・比容積）を表示
- **状態点の追加**: 任意の 2 値から状態を求めて作図
  - 乾球温度 + 相対湿度 / 湿球温度 / 絶対湿度 / 露点温度 / 比エンタルピー
  - 湿球温度 + 相対湿度、比エンタルピー + 相対湿度 / 絶対湿度
  - 線図クリックでの追加、ドラッグでの移動
- **状態変化と熱量計算**: 2 点間の Δt・Δx・Δh・SHF、風量 [m³/h] を与えると全熱・顕熱・潜熱 [kW] と水分量 [kg/h]
- **混合**: 2 つの空気を風量比（乾き空気の質量流量に換算）で混合した点を作図
- **SHF 線・装置露点（ADP）**: 基準点から指定 SHF の線を引き、飽和曲線との交点を表示
- **大気圧補正**: 標高 [m] または大気圧 [kPa] を指定（高地の線図）
- **表示範囲・表示線の切り替え**
- **書き出し**: SVG / PNG（2 倍解像度）/ CSV（Excel 対応 BOM 付き）、A4 横での印刷
- 入力内容はブラウザ（localStorage）に自動保存

## 使い方

1. `index.html` をブラウザで開く
2. 「サンプル（夏期冷房）」で外気・還気・混合・吹出の例を表示できます
3. 左のフォームから状態点・変化線・混合・SHF 線を追加します

## 計算式

ASHRAE Handbook — Fundamentals (2017) 第 1 章に基づく理想気体近似です。

- 飽和水蒸気圧: Hyland–Wexler 式（0 °C 未満は氷面）
- 絶対湿度: x = 0.621945 · pw / (P − pw)
- 比エンタルピー: h = 1.006 t + x (2501 + 1.86 t) [kJ/kg(DA)]
- 比容積: v = 0.287042 (t + 273.15)(1 + 1.607858 x) / P [m³/kg(DA)]
- 湿球温度: 断熱飽和の式を二分法で解く
- 標高補正: P = 101.325 (1 − 2.25577×10⁻⁵ z)^5.2559 [kPa]

顕熱・潜熱の分け方は、絶対湿度を入口値に固定した温度変化分を顕熱、残りを潜熱としています。
