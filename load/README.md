# 冷暖房負荷計算シート（Web版）

Excel「冷暖房負荷計算シート」（基本／輻射暖房／負荷手計算）をブラウザで使えるようにしたツールです。
住宅の冷暖房負荷を **顕熱・潜熱に分けて** 計算し、エアコンの吹出し風量・能力や床下温水配管の放熱量も確かめられます。

インストール不要で、パソコン・スマートフォンのブラウザで動きます。入力値はブラウザの中だけで計算され、外部には送信されません。

## 使い方（かんたん）

1. 公開版 https://hironishimura.github.io/airconditioning/load/ を開きます（またはこのフォルダの `index.html` をブラウザで開きます）。
2. 画面上部の「入力例」で原表の数値を読み込むと、すぐに計算結果とグラフが表示されます。
3. 室温・外気温・換気量・家電の台数・窓面積・UA値などを自分の条件に書き換えます。入力するたびに再計算されます。
4. 「合計負荷」がプラスなら冷房、マイナスなら暖房が必要です。絶対値 ÷ 1000 が必要な能力（kW）の目安です。

詳しい手順・用語・すべての計算式は、アプリ内の **「使い方」「計算式の説明」タブ** にまとめています。

## 画面構成

| タブ | 内容 | 原表 |
| --- | --- | --- |
| 負荷計算 | 換気・人体・家電・日射・外皮・加湿除湿から顕熱／潜熱／合計負荷。内訳は家のイラスト（熱の出入りを矢印で表示）と棒グラフで確認 | 基本・輻射暖房シート 左側 |
| エアコン吹出し | 吹出口の大きさ・風速から風量、空気の混合、吹出し空気の状態、能力・顕熱比、到達距離・降下量 | 基本シート 右側 |
| 輻射暖房・床下 | 床下温水配管の放熱量、床・基礎の熱収支、床ガラリから出る空気の熱量 | 輻射暖房シート 右側 |
| 使い方 | 手順・符号の意味・保存方法・用語 | — |
| 計算式の説明 | すべての計算式と定数、原表のセル番地との対応 | — |

「負荷手計算」シートは、入力例の「空欄（手計算用）」に相当します。

## Web での公開

リポジトリ直下の `.github/workflows/pages.yml` が、main への push 時にテストを実行し、空気線図（ルート）とこのアプリ（`load/`）をまとめて GitHub Pages に公開します。

## ファイル

- `index.html` … 画面と説明文（使い方・計算式）
- `style.css` … デザイン（ライト／ダーク両対応、スマホ対応）
- `calc.js` … 計算エンジン（原表の数式を移植。各式に対応するセル番地をコメントで記載）
- `presets.js` … 入力例（原表の各シートの数値）
- `app.js` … 入力欄の生成・再計算・イラスト／円グラフ・保存
- `help.js` … 各枠の「？」ボタンで表示する説明文
- `../test/calc.test.js` … 原表の計算結果（68 セル）との一致を確かめるテスト

## テスト

```sh
node test/calc.test.js
```

原表「基本」「輻射暖房」シートに保存されていた計算結果と、このアプリの計算結果がすべて一致することを確認します。

## 注意

計算は簡易モデルによる目安です。機器選定はメーカー資料や詳細計算とあわせて判断してください。
原表の式をそのまま再現しているため、原表と同じ結果になります（再現した点の注記は「計算式の説明」タブの末尾にあります）。
